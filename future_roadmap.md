# Future Feature Roadmap - House Rent Management System (HRMS)

This document tracks potential enhancements and features for future development.

## 🚀 Planned Features

### 1. Tenant Experience
- [ ] **Payment Receipts:** Generate downloadable PDF receipts upon payment approval.
- [ ] **Maintenance Request System:** Ticket system for reporting issues (e.g., repairs) with status tracking (Pending $\rightarrow$ In Progress $\rightarrow$ Resolved).
- [ ] **Lease Reminders:** Automated notifications 30 days prior to lease expiration.
- [ ] **Payment Gateway Integration:** Integrate Stripe/PayPal for real-time financial transactions.

### 2. Owner Management & Analytics
- [ ] **Revenue Dashboard:** Visual charts showing total rent collected vs. outstanding payments.
- [ ] **Document Storage:** Cloud storage for lease agreements (PDFs) and property ownership deeds.
- [ ] **Tenant Screening:** Profiles including contact history and previous landlord references.
- [ ] **Expense Tracking:** Log property-related costs (taxes, repairs) to calculate net profit.

### 3. Super Admin Governance
- [ ] **System Audit Logs:** Track administrative changes (who changed what and when).
- [ ] **User Activity Monitoring:** Analytics on login patterns and API usage.
- [ ] **Global Reporting:** Export occupancy rates and system-wide financial summaries to CSV/Excel.

### 4. Technical & Security Enhancements
- [ ] **Webhooks:** Event-driven notifications for external systems (e.g., lease signed).
- [ ] **Advanced API Filtering:** Implement complex query parameters for API endpoints (e.g., city, price range).
- [ ] **Two-Factor Authentication (2FA):** Enhanced security for privileged accounts (Owners/Admins).

## 📋 Proposed Implementation Order
1. **Maintenance Requests** (Foundation for service management)
2. **Revenue Dashboard** (Data visualization and reporting)
3. **PDF Receipts** (Document automation)
4. **Payment Gateway** (Financial automation)
